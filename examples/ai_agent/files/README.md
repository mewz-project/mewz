# Mewz AI Agent Demo

This directory contains a short README bundled into Mewz's read-only filesystem.
The agent can read this file with the `read_file` tool when you ask it to inspect README.

## About Mewz

Mewz is a unikernel designed specifically for running Wasm applications.
It links a single Wasm application into the kernel at build time.

## Demo tasks

- `Calculate 2+2`
- `What time is it now?`
- `Double the current minute`
- `Read the README`
